# NeteaseQQRegisterHelper

对网易云音乐 Android **9.6.08** 中「QQ 授权后要求绑定手机号」流程进行兼容性与流程诊断的研究项目，目标运行环境为 **NyaZygisk + Vector**。

> **当前状态：研究脚手架阶段，尚未提供可安装 APK，也没有声称已经验证可用。**

## 目标与边界

- 确认模块能否在 Vector 环境中加载到网易云音乐进程。
- 记录 QQ 授权回调后的页面跳转、客户端提示和异常日志，定位流程终止的位置。
- 区分客户端 UI/兼容性问题与服务端要求的手机号验证。
- 仅在确认合法、受支持的流程后，再决定是否开发后续功能。

本项目不会伪造注册成功、伪造服务端响应、篡改账号状态，也不会仅通过隐藏绑定页面来声称已成功注册。隐藏界面并不等于服务端创建了有效账号。

## 目前已知

- 目标应用版本：网易云音乐 Android 9.6.08
- 触发场景：选择 QQ 授权后出现手机号绑定页面；退出后注册流程终止
- 运行环境：NyaZygisk + Vector
- 尚缺：设备 Android 版本、Vector 版本、网易云音乐包名确认、相关 logcat 日志、QQ 授权后服务端/客户端返回结果

## 下一步

1. 收集设备与框架版本信息。
2. 取得脱敏后的授权流程日志，确认模块是否成功加载以及终止发生的位置。
3. 在不修改账号验证结果的前提下，建立最小诊断模块并测试加载。
4. 根据证据判断是否存在普通客户端兼容性问题，或该流程确实要求手机号验证。

详见 [诊断计划](docs/analysis-plan.md) 与 [环境信息清单](docs/environment-info.md)。
