# 流程诊断计划

## 阶段 1：确认环境

收集 Android 版本、CPU 架构、Vector 版本、NyaZygisk 版本、网易云音乐包名与版本号。先确认目标包名和模块作用域，不猜测应用内部类名。

## 阶段 2：复现界面流程

在用户主动操作时记录以下时间点：

1. 启动网易云音乐。
2. 点击「QQ 登录」。
3. QQ 授权返回网易云音乐。
4. 手机号绑定页面出现。
5. 用户返回/取消，流程终止。

诊断版会记录模块初始化、目标包进程，以及可用时的 Activity 类名。日志不得包含页面文字、输入内容、Intent 中的授权数据或网络请求正文。

## 阶段 3：最小模块与页面诊断

先验证模块是否被 Vector 发现、是否进入目标应用进程，以及是否出现“Activity resume diagnostic hook installed”。如果该 Hook 不可用，保留其他加载日志，不应影响网易云音乐正常运行。

## 阶段 4：依据证据决策

- 若是模块/客户端兼容问题：修复加载与诊断代码。
- 若流程由服务端要求手机号验证：记录为服务端约束，不伪造验证结果，也不把隐藏界面当作注册成功。
- 若官方支持其他登录或注册入口：记录其可复现步骤与限制。

## 验收标准

- 自动构建成功，并验证 APK 内的入口和作用域元数据。
- 能证明模块是否加载到正确的目标进程。
- 能在 Hook 可用时记录 Activity 类名，但不记录凭证或表单内容。
- 不将页面消失误判为账号创建成功。
