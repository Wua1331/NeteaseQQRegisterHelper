# 流程诊断计划

## 阶段 1：确认环境

收集 Android 版本、CPU 架构、Vector 版本、NyaZygisk 版本、网易云音乐包名与版本号。先确认目标包名和模块作用域，不猜测应用内部类名。

## 阶段 2：记录现象

在用户主动操作 QQ 授权时，记录以下时间点：

1. 启动网易云音乐。
2. 点击 QQ 授权。
3. QQ 授权返回网易云音乐。
4. 手机号绑定页面出现。
5. 用户返回/取消，流程终止。

日志中应重点区分：模块未加载、类/方法兼容异常、Activity 跳转异常、网络错误、服务端明确要求绑定手机号。提交前必须对日志脱敏。

## 阶段 3：最小模块加载验证

先验证模块是否被 Vector 发现、是否进入目标应用进程，以及日志输出是否正常。第一版只做诊断，不拦截注册、网络或账号验证逻辑。

## 阶段 4：依据证据决策

- 若是模块/客户端兼容问题：修复加载与诊断代码。
- 若是服务端要求手机号验证：记录为服务端流程约束；不伪造验证结果，不制造虚假的注册成功状态。
- 若存在官方支持的其他注册入口：记录可复现步骤与限制。

## 验收标准

- 有明确的构建环境与可复现步骤。
- 能证明模块是否加载到正确的目标进程。
- 日志中不包含账号令牌、验证码或其他敏感信息。
- 不将页面消失误判为账号创建成功。
