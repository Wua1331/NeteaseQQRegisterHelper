# 环境信息清单

请补充以下信息，便于选择正确的模块 API 和构建配置。

- [ ] 手机型号（可只写型号，不需要序列号）
- [ ] Android 版本与 API level
- [ ] CPU 架构（通常为 arm64-v8a）
- [ ] NyaZygisk 版本
- [ ] Vector 版本
- [ ] 网易云音乐版本确认：9.6.08
- [ ] 网易云音乐包名（可在应用信息或模块管理器中查看）
- [ ] Vector 中是否已将模块作用域勾选到网易云音乐
- [ ] QQ 授权返回后出现绑定页时的脱敏日志

## 获取日志注意事项

可以在复现前后使用系统日志工具记录相关错误。分享前删除所有访问令牌、Cookie、手机号、验证码、OpenID、账号 ID 和个人信息。不要分享完整登录请求/响应正文。
